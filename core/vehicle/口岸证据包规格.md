# PRMS-V 口岸级车辆通行证据包（V1.1）

> 对标海关/口岸「一趟车一条记录 + 多模态留证」；实现见 `evidence_export.py`、`camera_service.py`、`alarm_clip_recorder.py`。

## 1. 何时生成

- **触发**：本趟 **有效结束**（无 `invalid_reason`）且 **辐射硬报**。
- **更新**：每增加 `entry/alarm/exit/plate` 图或 `video` 片段后 **重新打包 zip**。
- **路径**：`{抓拍目录}/evidence/{passage_id}/` 与 `{passage_id}.zip`。

## 2. 目录结构

```text
evidence/{episode_id}/
  README.txt
  manifest.json       schema: PRMS-V/evidence/1.1
  radiation.json
  images/
    entry.jpg
    alarm.jpg
    exit.jpg
    plate.jpg         # 识牌 HTTP multipart / Base64
  video/
    alarm_clip.mp4    # 硬报：约 5s 缓冲 + 5s 续录（子码流 8fps）
```

## 3. 采集策略

| 节点 | 角色 | 说明 |
|------|------|------|
| 入口开趟 | `entry` | ISAPI，失败 RTSP 单帧 |
| 硬报沿 | `alarm` | 同上 |
| 硬报沿 | `video` | 独立子码流环形缓冲 + 导出 mp4（与预览并行） |
| 出口关趟 | `exit` | ISAPI；无 alarm 图时再补 alarm |
| 识牌 POST | `plate` | `parse_plate_payload`：multipart/XML/JSON 图片 → `plate_*.jpg` |

`image_paths`：`entry|…;alarm|…;video|….mp4;plate|…`

## 4. manifest 扩展（1.1）

- `clip_seconds`: `{ "pre": 5, "post": 5, "total_target": 10 }`
- `files[]`: `video` 指向 `video/alarm_clip.mp4`

## 5. 浏览方式

- **不内嵌 NVR**；审计员解压 zip 后 **双击 mp4**（系统播放器）即可。
- 上位机总览仍以 **单张 alarm/exit 图** 为主；视频只在证据包内。

## 6. 运维

- 相机需 **子码流 RTSP**（建议 Channels/102）；同机位会占 **预览 + 缓冲 + 导出** 多路拉流，码流勿过高。
- 归档 **SITE/MACHINE** 填入口岸编号。
- 日志：`PRMS-V evidence bundle`、`PRMS-V capture`、`clip:` 失败原因。
