## 1. 配置（QSettings / ConfigManager）

| 键 | 类型 | 说明 |
|----|------|------|
| `VEHICLE_RTSP_URL` | str | 预览 RTSP，建议 `.../Channels/102?...` |
| `VEHICLE_CAMERA_HOST` | str | 可选；空则从 RTSP 解析 |
| `VEHICLE_CAMERA_USER` | str | 可选；空则从 RTSP 解析 |
| `VEHICLE_CAMERA_PASSWORD` | str | 可选；空则从 RTSP 解析 |
| `VEHICLE_CAMERA_ISAPI_CHANNEL` | int | ISAPI 抓图通道，默认 **101**（与主码流一致） |
| `VEHICLE_CAPTURE_DIR` | str | 抓拍保存目录，默认 `~/daq_tablet/vehicle_captures` |

## 2. 模块职责

| 模块 | 职责 |
|------|------|
| `camera_config.py` | `VehicleCameraConfig`、`load_vehicle_camera_config()` |
| `hik_isapi.py` | `fetch_isapi_snapshot(config) -> bytes \| None` |
| `camera_service.py` | `VehicleCameraService`：硬报抓拍、收车牌、异步线程 |
| `rtsp_preview.py` | `RtspPreviewWidget.grab_jpeg_bytes()` 作抓拍兜底 |
| `passage_fsm.Passage` | 字段 `image_paths`（`;` 分隔本地路径） |
| `dashboard_model` | 模型键 `alarm_image`（硬报态显示） |

## 3. VehicleCameraService 公开 API

```python
class VehicleCameraService(QObject):
    capture_done = pyqtSignal(str, str)   # passage_id, file_path
    capture_failed = pyqtSignal(str, str) # passage_id, reason
    plate_ingested = pyqtSignal(str, str) # passage_id, plate

    def reload_config(self, cfg: VehicleCameraConfig) -> None: ...
    def on_hard_alarm_edge(self, passage: Passage, rtsp_fallback=None) -> None:
        """decision 首次进 HARD 时调用一次。"""
    def ingest_plate(self, plate: str, passage_id: str | None = None) -> bool:
        """相机 ANPR / 平台推送车牌；未手补时写入 open Passage。"""
```

- `rtsp_fallback`: `Callable[[], bytes | None]`，由主窗口传入 `vehicle_page.capture.grab_jpeg_bytes`。

## 4. 主程序挂接点（MainWindow / ui_base）

| 时机 | 调用 |
|------|------|
| 启动 / 改 RTSP | `_sync_vehicle_rtsp()`、`VehicleCameraService.reload_config()` |
| 每包 L2 `_vehicle_on_summary` | `on_packet` **前**记 `prev_hard`；**后**若 `open.hard_alarm and not prev_hard` → `on_hard_alarm_edge` |
| 抓拍完成 | 更新 `Passage.image_paths` → `_flush_vehicle_dashboard()` |
| 手补车牌 | 不变；`ingest_plate` 不覆盖 `plate_manual=True` |

## 5. ISAPI（海康）

```http
GET http://{host}/ISAPI/Streaming/channels/{channel}/picture
Authorization: Digest ...
```

- 默认 `channel=101`（可在设置改为 102 抓子码流图，一般留证用 101）。
- 实现见 `hik_isapi.py`（标准库 `urllib`，无额外依赖）。

## 6. 相机识牌（二期 · 已实现 HTTP 骨架）

| 方式 | 接入 |
|------|------|
| **HTTP 报警主机** | `plate_http_server.py` 监听 → `ingest_plate()` |
| FTP 上传 | 未做 |
| ISAPI 订阅 | 未做 |

### 6.1 端口与 IP（与探头 TCP 分开）

| 用途 | 方向 | 地址 | 端口 |
|------|------|------|------|
| 探头能谱 TCP | 探头 → 上位机 **监听** | 192.168.0.201 | **8234** |
| 主控 L2 TCP | 主控 → 上位机 **监听** | 192.168.0.201 | **8235**（多端口模式） |
| **相机识牌 HTTP** | 相机 → 上位机 **监听** | 192.168.0.201 | **8236**（默认，可改） |
| RTSP 预览 | 上位机 → 相机 **拉流** | 相机 IP | **554**（相机侧，PC 不监听） |
| ISAPI 抓拍 | 上位机 → 相机 **请求** | 相机 IP | **80**（相机侧） |

**8234/8235 不用改**；二期 **新增 8236**（或你在设置里改的端口），Windows 防火墙需 **入站放行 TCP 8236**。

相机 Web「报警主机 / HTTP 监听」示例 URL：

`http://192.168.0.201:8236/hik/anpr`

（路径任意 POST 均可解析，推荐与上表一致便于文档统一。）

### 6.2 写入规则

- 仅当存在 **进行中本趟**（入口红外已开 `Passage`）时写入 `plate`。
- 已 **手补** 且非空时不覆盖。

## 7. UI

- 空闲/过车：RTSP 预览。
- `banner_tone == alarm` 且 `alarm_image` 非空：中间区 **优先显示抓拍图**（可叠 RTSP 角标「留证」）。
